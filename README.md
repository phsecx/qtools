# 🛠️ Q Tools

Advanced developer toolkit that runs 100% in your browser. No servers, no APIs, no tracking — just pure client-side magic.

🔗 **Live Demo:** [dashtools.ddns.net](https://dashtools.ddns.net)

---

## 🎯 Features

- **QR Code Studio** — 8 types + batch ZIP export
- **Age Calculator** — with zodiac & milestones
- **Encode/Decode** — 9 codecs + SHA/MD5 hashing
- **Generator Hub** — Text repeater, Emoji, Password, UUID, Colors
- **Device Info** — Browser, OS, Battery, Network
- **Typing Test** — Live WPM tracking
- **Stats Dashboard** — Usage analytics & achievements

## ⚡ Tech Highlights

- **PWA** — Install on desktop & mobile, works offline
- **Zero external APIs** — everything runs locally
- **Single HTML file** — no build tools needed
- 5 themes, 8 achievements, easter eggs 🥚

## 🖥️ Hosting

Self-hosted on a personal VPS (Nginx + Let's Encrypt SSL) — full control, zero third-party hosting.

## 🛠️ Built With

HTML5 · CSS3 · JavaScript · Tailwind CSS
